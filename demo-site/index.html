Why is this quantum-safe?

The Stellar account's Ed25519 key has masterWeight=0, meaning it can never authorize transactions. Only preAuthTx (added after SPHINCS+ verification) can move funds. Even if quantum computers break Ed25519, attackers cannot drain the wallet.

How X402 Works:

  1. Request hits a paid endpoint → Server returns 402 with payment requirements
  2. Wallet signs payment with spending account (Ed25519)
  3. Request retries with X-PAYMENT header
  4. Server verifies payment via facilitator and returns content
